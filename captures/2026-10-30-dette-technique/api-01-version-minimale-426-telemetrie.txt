== Version minimale d'app (RG-SYNC-27) — serveur : pos.app.min-version = 0.1.0
  GET /sync/pull  X-App-Version: 0.0.9  → HTTP 426 {"code":"UPGRADE_REQUIRED","minAppVersion":"0.1.0","appVersion":"0.0.9","message":"Mise à jour requise : version minimale 0.1.0 — l'app continue hors ligne, synchronisation suspendue"}
  GET /sync/pull  sans X-App-Version     → HTTP 426 (ancienne app muette = refusée)
  GET /sync/pull  X-App-Version: 0.1.0  → HTTP 200 (app à jour)
  GET /pos/lan-key X-App-Version: 0.0.1 → HTTP 426 (tous les appels appareil sont couverts)
  GET /stores/{id}/supervision/alerts (JWT back-office, sans version) → HTTP 200 (le back-office n'est pas concerné)
